Idea Platform Plugin

让编辑器里的 Agent 读取 Idea Platform，而不是去爬网页。

信使亭
原来的想法
Agent 要参与一个想法，应该读站点准备好的上下文，而不是把网页刮下来。
拿出来之后
Cursor 插件。用 MCP 列出公开想法、读取上下文；只有带上分支凭证才写回进展。编辑器里的 Agent 从这里取想法，而不是去爬网页。
我做的取舍
没有分支凭证时，不向 Agent 宣传写接口。许可是 MIT。
材料
JavaScript

它解决什么问题

Agent 要参与一个想法，应该读站点准备好的上下文，而不是把网页刮下来。

访客如何使用

可以装进 Cursor，也可以直接跑这个 stdio MCP。默认请求 Idea Platform 的线上站，也可以用环境变量改基址。

关键交互

公开工具可以搜索想法、读取想法和作品。设置了分支凭证之后，才会出现写入。未确认的写入会被拒绝。

我做的取舍

没有分支凭证时，不向 Agent 宣传写接口。许可是 MIT。
