ResourceSteward

在菜单栏看清 CPU、内存和 GPU，再决定要不要处理某个后台应用。

管家小屋
原来的想法
软件会根据用户习惯动态进行推荐，让用户在不同的场景下规划CPU、内存等资源
拿出来之后
按负载建议降低优先级，或请求应用正常退出。不压缩内存，不读取窗口和剪贴板。烟囱里冒的是负载曲线。
我做的取舍
降低优先级不会回收内存。退出之后的回收交给系统。
材料
Swift
  • 查看源码 ↗

它解决什么问题

机器变慢时，需要先看清是谁在占用，再选择要不要处理。建议应该可以被拒绝。

访客如何使用

从仓库构建。需要 macOS 13 或更新版本，以及 Swift 6。应用数据在 ~/Library/Application Support/ResourceSteward/。

关键交互

  • 菜单栏里看 CPU、内存和 GPU。
  • Level 0 在确认后执行建议。Level 1 自动执行，并给出通知。
  • 建议来自 README 中称为 Jev 的决策：候选、模型评估、保护规则和节流。

我做的取舍

  • 降低优先级不会回收内存。退出之后的回收交给系统。
  • 不直接压缩内存或清理显存，也不读取窗口内容和剪贴板。
  • 启用模型评估后，候选应用和负载会发到你自己配置的模型服务。诊断日志留在本机。
