它解决什么问题

GORM 没有现成的 Oracle 用法时，需要一个能打开连接、跟着 GORM 走的驱动。

访客如何使用

安装是 go get github.com/cengsin/oracle。打开数据库用 gorm.Open(oracle.Open(连接串), &gorm.Config{})。需要 Oracle 12c 或更新版本、Go 1.13 或更新版本，以及 ODPI-C。

我做的取舍

仓库 README 写明不建议用于生产。驱动在另一份实现上继续适配，而不是从零重写 Oracle 协议。
