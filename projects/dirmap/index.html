DirMap

目录一变，就给 Agent 一份带简短说明的结构。

它解决什么问题

Agent 要看懂一个项目，不该每次都重新扫一遍没有说明的目录树。

访客如何使用

配置要监视的路径、输出目录，以及兼容 Claude 的接口。可以本地运行，也可以用 Docker。

我做的取舍

macOS 上的 Docker 收不到可靠的文件系统事件，所以提供轮询。说明写多长、准不准，取决于你配置的模型。
