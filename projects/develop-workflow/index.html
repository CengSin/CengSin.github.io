develop-workflow

把开发和 Agent 的步骤编排成失败后可以单独重试的流程。

它解决什么问题

一步失败就整段重来，开发和 Agent 的流程都很难改。步骤应该能单独重试。

访客如何使用

仓库里有 Temporal worker、命令行和 Docker Compose。本地会起 Temporal、它的界面和 Redis。

我做的取舍

这是一套可以在自己机器上跑起来的结构，不是一个公开的在线服务。
