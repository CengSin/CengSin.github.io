Fish Audio MCP

把文字交给 Fish Audio，接进支持 MCP 的客户端。

它解决什么问题

支持 MCP 的客户端需要一个文字转语音的工具，而不是单独打开 Fish Audio 的网站。

访客如何使用

安装依赖后，在本地 .env 写入自己的 API key 和模型 ID，再启动服务。
